* AAA (authentication, authorization, accounting) a security framework
* ABAC (attribute based access control)
* AES (advanced encrytption standard)
* ARP (address resolution protocol) used to map an IP address with MAC address
* APT (advanced persistent threat) a cyber attack in which an unathorized user gains access to system and remains undetected for a while
* BCP (business continuity planning) startegy for ensuring organization's ability to prevent disruption
* BIA (business impact analysis) identify the operational and financial impacts resulting from the disruption of business functions
* BPA (business partnership agreement) between 2 companies
* CVE (comman vulnerabilities and exposure)
* DHCP (dynamic host configuration protocl) used to automatically assign IP address and other network settings on devices
* GDPR (general data protection regulation) european union law on data protection
* IAM (identity and access management) enables IT administrators to restrict access to organization resources 
* ICMP (internet control message protocl) used by network devices to diagnose network communication issues
* IDS (intrusion detection system) a monitoring system that detects suspicous activities and generates alerts
* NDA (non disclosure agreement) contract that prevents any side of the business to give away the secrets
* PPP (point to point) a protocol used to establish a direct connection between 2 devices
* RADIUS (remote authentication dial-in user service) used to provide centralized AAA management for users
* S/MIME (secure/multipurpose internet mail extentions) standard for secure email messaging that provides encryption and digital signing capabilities
* SIEM (security information and event management) provides real-time analysis of security alerts
* SMTP (simple mail transfer protocol)
* SOAR (security orchestration, automation adn reponse) helps organizations automate their security operations
